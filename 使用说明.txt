        Codex 中文启动器 · 使用说明
═══════════════════════════════════════════════════════════

【一、功能介绍】

  本工具用于为 macOS 版 Codex 桌面应用启用简体中文界面,
  并提供一键启动/重启中文版的便捷入口。

  它的原理并不是翻译,而是"解锁":Codex 官方安装包内本来就
  自带完整的简体中文语言资源(菜单、界面文案等),只是默认被
  功能开关锁在英文。本工具在本地修改副本应用内的开关与语言
  设置,让官方中文资源生效。

  特点:
    · 完全离线:全过程只在你的电脑上进行,不联网、不发送
      任何数据;
    · 不动原版:不修改"应用程序"文件夹里的原版 Codex.app,
      而是生成一个独立的『Codex 中文版.app』副本,两者可
      并存使用;
    · 一键启停:主按钮自动识别状态(汉化并启动 / 启动中文版
      / 重启中文版),安装过程有 SMO 渐变进度条;
    · 可随时卸载:通过本工具的卸载功能把中文版副本移入
      废纸篓即可,不留残余。

【二、系统要求】

    · macOS 13 (Ventura) 或更高版本;
    · Apple 芯片(M1/M2/M3/M4)与 Intel 芯片均可使用 ——
      本工具本身是纯脚本,不区分架构;安装出的中文版副本
      会自动采用你电脑上官方原版的架构,无需单独选版本;
    · 已安装官方 Codex 桌面版。注意:它在"应用程序"文件夹
      里的名字可能是 ChatGPT.app,也可能是 Codex.app(内部
      标识都是 com.openai.codex),本工具会自动识别;
    · 无需安装任何其他软件。

【三、使用步骤】

  1. 双击打开 DMG 镜像,里面有一个应用程序:
     『Codex中文启动器.app』(可将其拖到"应用程序"文件夹,
     也可以直接在镜像里双击运行);

  2. 双击运行『Codex中文启动器.app』,窗口有三个按钮:
        〔使用说明〕 〔卸载汉化〕 〔主按钮〕
     主按钮会根据状态自动变化:
       · 尚未安装时显示〔汉化并启动〕——点击后终端出现
         SMO 横幅与渐变进度条,安装完成自动打开中文版
         (约 1-2 分钟,完全离线);
       · 已安装时显示〔启动中文版〕;
       · 中文版正在运行时显示〔重启中文版〕;

  3. 也可以随时到"个人应用文件夹"(访达左侧边栏"个人收藏"
     → "应用程序",即 ~/Applications)双击『Codex 中文版.app』
     运行,界面即为简体中文。

  ★ 首次打开时的注意事项(重要):

  因为副本使用的是本地临时签名(ad-hoc 签名,无需联网,
  但没有开发者证书),首次打开可能提示:
      "无法验证此 App 是否不含恶意软件"
      或 "『Codex 中文版』已损坏,无法打开"

  这不是真的损坏,处理方法二选一:
      方法一:在访达中右键点击『Codex 中文版.app』,
              选择"打开",再在弹窗中点"打开";
      方法二:打开 系统设置 → 隐私与安全性,下拉找到
              相关提示,点"仍要打开"。

  之后再次打开就不会再提示了。对启动器 app 本身同理。

【四、卸载方法】

  再次运行『Codex中文启动器.app』,点〔卸载汉化〕,
  中文版副本会通过 Finder 移入废纸篓(后悔了可以从废纸篓
  找回)。

  卸载只删除本工具创建的『Codex 中文版.app』副本:
    · 原版 Codex.app 完全不受影响;
    · 你的登录状态、聊天记录等个人数据不受任何影响
      (聊天数据与原版共用,并不存放在副本里)。

【五、常见问题】

  问:Codex 官方更新后,汉化还能用吗?
  答:Codex 每次更新后,其内部与语言开关相关的代码可能发生
      变化,导致本工具提示"当前版本的语言代码与补丁不兼容"
      之类的错误。这属于正常现象,请等待本工具推出对应新版
      的适配后再使用;原版 Codex.app 不会因此受影响。

  问:装好中文版后,能不能把原来的 ChatGPT.app 删掉省空间?
  答:技术上可以,但有几点务必先了解,我们建议保留原版:
      1. 中文版副本是独立完整的,删掉原版后中文版仍能正常
         运行,聊天数据也都在(数据存放在
         ~/Library/Application Support/Codex,不在任何一个
         app 里);
      2. 但 Codex 官方不断更新,更新后需要用本工具基于
         【新版原版】重新汉化。删了原版,以后就没有汉化
         的"原料"了,只能去官网重新下载;
      3. 若汉化副本出现问题,原版是现成的回退方案;
      4. 中文版副本不会自动更新(更新会覆盖汉化),保留原版
         也可让原版先接收更新、确认新版可用后再重新汉化。
      综上:如果磁盘空间实在紧张,可以删;否则建议保留。

  问:使用汉化会影响原版或聊天数据吗?
  答:不会。本工具从不修改原版,所有改动只发生在独立副本上;
      聊天数据也不会被修改或删除。

  问:想重复安装 / 更新汉化怎么办?
  答:请先点〔卸载汉化〕删除旧的中文版副本,再重新点
      〔汉化并启动〕完成安装。工具不支持在旧副本上覆盖安装。

  问:点〔汉化并启动〕后提示"未找到 Codex 桌面版"?
  答:请确认已安装官方 Codex 桌面版(应用名可能是 ChatGPT 或
      Codex;工具会自动搜索 /Applications、~/Applications 与
      Spotlight)。若安装在特殊位置,可在"终端"中用命令行安装:
          /usr/bin/perl <工具路径>/Contents/Resources/codex-zh.pl \
              install --app /实际路径/ChatGPT.app \
              --destination ~/Applications/Codex\ 中文版.app
